# Arch 03 — Long Context

A deep technical dive into extending LLM context windows: the quadratic attention bottleneck, Rotary Position Embeddings (RoPE) and their interpolation failure mode, position interpolation and NTK-aware scaling, YaRN's non-uniform scaling with attention temperature correction, ALiBi's linear bias alternative, sliding-window attention with sink tokens (StreamingLLM), ring attention and sequence-parallel context distribution, and Mamba-attention hybrid architectures for very long context.
